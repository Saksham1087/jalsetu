# PDF Report Generation

## Description
Generate a formatted PDF complaint report entirely on the client side using pdfmake. The PDF must include all complaint fields, a photo (if present), timeline, and a professional header/footer.

## Triggers
- User clicks "Download Report" on the complaint form success view
- User clicks "Download Report" on their complaint detail drawer
- Admin clicks "Download Report" on the admin complaint detail panel

## Input
A complaint object with the following fields (may come from Firestore snapshot or localStorage/demo data):
```
{
  id: string,
  userName: string,
  type: string,
  description: string,
  images: string[],
  latitude: number, longitude: number,
  address: string | null,
  ward: string | null,
  landmark: string | null,
  mobile: string | null,
  createdAt: string (ISO) | Date,
  updatedAt: string (ISO) | Date,
  status: 'submitted' | 'acknowledged' | 'in_progress' | 'resolved' | 'rejected',
  timeline: [{ status, timestamp, note }],
}
```

## Output
A PDF file downloaded to the user's device. File naming: `{userName}-{type}-{date}.pdf`. The userName is sanitized (spaces → hyphens, special chars removed). The type is the formatted display type. The date is the complaint's creation date in DD-MMM-YYYY format.

## PDF Content Structure

1. **Header area**: JalSetu branding text ("JalSetu"), subtitle "Water Complaint Report", horizontal rule
2. **Metadata row**: Complaint ID (first 8 chars of UUID), Status with colored badge, Generation date
3. **Type section**: Complaint type with icon indicator (formatted label)
4. **Description section**: Full complaint description text
5. **Location section**: Address, Ward, Landmark, GPS coordinates in a table layout
6. **Contact section**: Reported by (user name), Mobile number, Submitted date, Last updated date
7. **Photo section**: Complaint photo (if present), centered, max width 400px
8. **Timeline section**: All timeline entries as a structured list with status, date, and note
9. **Footer**: "Generated by JalSetu — {date}" with page number

## Styling
- Primary color: teal (#127A7A) for headers and accents
- Status colors match existing statusConfig: deep (#0F2E35), teal (#127A7A), brass (#C8914A), green (#2E7D5A), red (#C44A3A)
- Clear section headings with bottom borders
- Readable font sizes (10-16pt range)
- Page margins: 40pt top/bottom, 40pt left/right
